How It Works: The Hybrid Approach
Rules do 90% of the heavy lifting at lightning speed; the local Edge Model steps in for contextual Indian names and addresses.
Pass 1: Deterministic Engine >5,000 rec/sec

⚡ MaskFlow Statutory Rules

Uses exact mathematical checksums to eliminate false alarms on random numbers across Excel, CSV, Word, PDF, and live Tally ERP accounts:

  • Aadhaar ($D_5$): UIDAI-mandated Verhoeff dihedral group algorithm.
  • GSTIN (Mod-36): State code prefix + embedded PAN + 15th check digit.
  • PAN Card: Statutory regex + legal entity classification (P, C, F, T, H).
  • Banking & UPI: RBI IFSC branch routing codes and UPI handles.
Pass 2: Contextual AI Zero GPU Needed

🧠 Local Edge Model AI

Catches what rules and regex cannot: unstructured Indian names, physical addresses, medical records, and children's data:

  • Lightweight NER Architecture: Small 200–500MB model (GLiNER / ONNX Runtime) running on client CPU.
  • Indian Name Accuracy: Identifies diverse regional Indian naming patterns where regex tools fail (<30% accuracy).
  • Ordinary Hardware: Runs smoothly on everyday SMB/CA laptops (Core i3, 8GB RAM).
  • 100% In-Process: Model weights execute locally; zero text leaves the PC.

Step 3

Dual-Engine Audit

Step 4

Instant Redaction

Step 5

Governance Report
